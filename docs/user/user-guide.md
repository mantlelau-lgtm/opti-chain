# 使用手册

## 功能概览

| 模块 | 页面 | 核心能力 |
| --- | --- | --- |
| 基础数据 | 物料 / 供应商 / 客户 / 仓库 / 库位 | 主数据 CRUD + 准入审核 + 信用额度 |
| 采购 | 采购订单 | 订单状态机、收货闭环、收货记录追溯 |
| 销售 | 销售订单 | 审批锁库防超卖、信用控制、取消释放 |
| 仓储 | 实时库存 / 出入库 | 库存查询（含锁定量）、手工出入库、流水审计 |
| 计划 | 计划/MRP | 需求管理、MRP 运算、建议转采购单 |

## 基础数据

- **物料**：`min_stock` 作为 MRP 安全库存参与运算；`max_stock` 目前仅记录，未启用预警。
- **供应商**：新建默认「待审核」。**只有「已核准」供应商才能创建采购订单**（准入管控）。行内「核准 / 驳回」切换审核状态。
- **客户**：`信用额度` > 0 时启用信用控制，审批销售订单时占用、取消时释放；额度为 0 表示不启用。新建默认「已核准」，驳回后禁止新建销售订单。
- **仓库 / 库位**：库存按「仓库 + 库位 + 物料」三元组记账，库位可为 0（仓级统账）。

## 采购订单

状态机：`草稿 → 已审批 → 进行中 → 已完成`，任意阶段可「已取消」。

- **编辑**：仅可改表头（单号/供应商/日期/创建人）；明细建单后不可改，状态与收货进度不受编辑影响。
- **收货**（仅已审批/进行中）：
  - 每行填「合格入库」与「拒收」两个数量；**拒收必须填原因**（退换货依据）。
  - 合格数量 → 入所选仓库库存 + 写流水 + 累计到订单「已收」。
  - 拒收数量 → **不入库存**，保留在「在途」中等待供应商补货。
  - 合格量累计收满全部明细 → 订单自动「已完成」。
  - 防超收：累计合格不得超过订购量，超出直接拒绝。
- **收货记录**：行内按钮查看每轮收货的到货/合格/拒收/原因。
- 拒收部分不打算追补时，手工把状态改为「已完成」关单。

## 销售订单

状态机：`草稿 → 已审批 →（发货中/已完成 预留）`，草稿/已审批可「取消」。

- **审批**：按「可用库存 = 实物 − 锁定」跨仓分配锁定库存；同时占用客户信用额度（启用时）。库存不足或信用超限都会被拒绝。
- **取消**：释放锁定与信用。
- **删除**：仅草稿可删；已审批必须先取消。
- 发货执行（shipped_qty 推进、出库扣减锁定）为后续版本能力，当前版本以锁定/释放管控为主。

## 仓储

- **实时库存**：展示实物数量与锁定数量；可用量 = 实物 − 锁定。
- **出入库**：手工入库（PURCHASE_IN 等）/ 出库（SALE_OUT，防超卖守卫：实物不为负）。单据删除当前不回冲库存（审计保留，注意操作顺序）。
- **流水**：所有库存变动的不可变履历（变动前/后数量）。

## 计划/MRP

- **需求**：来源 `FORECAST`（预测）或 `SALES_ORDER`；日期支持 `YYYY-MM-DD`。
- **运算**：按物料汇总 OPEN 需求，`建议采购量 = 毛需求 + min_stock − 现有库存 − 在途`，在途 = 未完结采购单的（订购量 − 已合格收货量），**含被拒收待补的量**；结果向下取整到 0。运算后需求置为已生成。
- **转采购单**：对建议行生成草稿 PO（供应商当前取首个供应商、单价 0，需人工完善——后续版本引入供应关系/价格表）。
