# 常见问题

## 安装相关

### 页面打不开 / 连接被拒绝（:5173）

vite 默认可能只监听 IPv6 回环 `[::1]`，浏览器走 IPv4 的 `127.0.0.1` 会失败。本项目 `vite.config.js` 已配置 `host: true`（监听所有地址）。若仍异常，重启 `npm run dev`。

### 后端报 `address already in use`

:8088 被旧进程占用。`lsof -nP -iTCP:8088 -sTCP:LISTEN` 找到 PID 后结束旧进程，或改用 `SCM_ADDR=:8089 go run ./cmd/server`（同时需调整 vite 代理目标）。

### 换了 MySQL 后启动报错

确认 DSN 含 `parseTime=True`，且数据库已创建（`CREATE DATABASE scm CHARACTER SET utf8mb4`）。表结构首次启动自动迁移。

## 使用相关

### 为什么不能给某个供应商下采购单？

准入管控：供应商必须「已核准」。到供应商页点「核准」后重试。报错信息为 `supplier is not approved (audit_status must be APPROVED)`。

### 收货时拒收数量为什么必须填原因？

拒收记录是退换货与供应商追责的依据，系统强制要求原因非空。

### 拒收的货去哪了？会占用库存吗？

不会。拒收数量**不入库存**，只记录在收货单上；同时保留在订单「在途」中，MRP 会继续把它算作待补量，直到补货收满或手工关单。

### 销售订单审批被拒，提示库存不足？

防超卖守卫：可用库存 = 实物 − 锁定。已有其他订单锁定了库存，或实物本身不够。取消无关订单释放锁定，或先补货。

### 审批被拒，提示 credit limit exceeded？

客户启用了信用控制且「已用 + 本单 > 信用额度」。取消部分订单释放额度，或在客户页调高额度。

### 编辑采购订单会改掉明细或收货进度吗？

不会。编辑只更新表头字段；明细、总额、状态、已收货量均保持不变。

### 库存单据删除后库存没变？

当前版本删除出入库单据**不回冲库存**（保留审计一致性），请通过新的反向单据调整库存。
