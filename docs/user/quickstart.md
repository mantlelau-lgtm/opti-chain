# 快速上手

## 前置条件

已按《安装部署指南》启动后端（:8088）与前端（:5173）。

## 5 分钟快速体验

1. **建主数据**
   - 供应商页新建供应商 → 点「核准」（未核准的供应商无法下采购单）
   - 物料页、仓库页各新建一条
2. **采购收货闭环**
   - 采购订单页「新建采购订单」（选供应商、加明细行）
   - 状态下拉改为「已审批」
   - 点「收货」：填合格数量；如有不合格，填拒收数量 + 拒收原因
   - 合格数量入库存，拒收不入库存、保留为在途等待补货；展开行可看「收货记录」
3. **销售防超卖**
   - 客户页新建客户（可设信用额度）
   - 先在出入库页「入库」给物料备点库存
   - 销售订单页新建订单 → 点「审批」：系统锁定可用库存并占用信用额度
   - 再建一张超过可用库存的订单审批 → 被拒绝（防超卖）
   - 「取消」订单 → 锁定与信用自动释放
4. **计划 MRP**
   - 计划/MRP 页新建需求（预测或销售订单来源）
   - 点「运算 MRP」：建议采购量 = 毛需求 + 安全库存(min_stock) − 现有库存 − 在途（在途含被拒收未补的量）
   - 对建议行点「转采购单」生成草稿 PO
